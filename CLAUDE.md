# smm-bot — ведение соцсетей через Claude

Пользователь пишет по-русски, отвечай по-русски, простым языком (он не программист).

## Площадки
- Instagram — `instagram.py` (готово), аккаунт prorab.artem (ID 17841404137234059).
  Токен системного пользователя (бессрочный): сетевой секрет окружения `smm-bot` для `graph.facebook.com`
  (или переменная `IG_TOKEN`). Для токена «вход через Instagram» — `IG_API=instagram`.
- Telegram — канал @spbpokoleniya, публикация через GitHub Actions (`.github/workflows/telegram.yml`):
  положить JSON {"text":..., "photos":[url,...]} в `telegram/outbox/`, закоммитить и запушить в main —
  бот опубликует и перенесёт файл в `telegram/sent/`. Токен — секрет репозитория TELEGRAM_BOT_TOKEN.
  Тест: `gh workflow run telegram.yml -f test_message=...`.
- MAX — ещё не подключён.

## Правила
- Никогда не публикуй без явного «да» пользователя на конкретный текст и медиа.
- Медиа для постов клади в `media/`, коммить и пушь в `main`; публичная ссылка:
  `https://raw.githubusercontent.com/adamec1213-sketch/smm-bot/main/media/<файл>`.
- Перед созданием контента читай профиль продукта (навык `product-marketing`,
  файл `.agents/product-marketing.md`). Если его нет — сначала собери его
  (после подключения Instagram — по `python instagram.py profile`).
- Тексты: навыки `social`, `copywriting`, `content-strategy`; видео — `video`; картинки — `image`.
- Токен бессрочный; `refresh` нужен только для режима `IG_API=instagram`.

## Фирменный стиль
- Чёрный фон + золото `#D9B05E` (как логотип «Поколения»), шрифт Montserrat (`brand/fonts/`).
- Логотип: `brand/logo.jpg`. Обложки Reels: `python brand/covers.py` → `drafts/covers/`.
- Текст обложки держать в центральной зоне 3:4 (y 240–1680 из 1920), чтобы не обрезался в сетке.

## Тексты без «ИИ-штампов»
- Навык `stop-slop` (`.claude/skills/stop-slop`, Hardik Pandya, MIT): прогонять через него подписи, сценарии и тексты слайдов перед показом пользователю.
- Для русского языка: тире там, где его требует пунктуация («Москва — столица», «от 20 000 ₽/м²»), оставлять; правило «no em dashes» относится к тире-«драматизации» вместо нормальной связи слов.

- Как считает конструктор П³: `sales/p3-kak-schitaet.md`. Сравнение с КП 18×30: `sales/p3-vs-kp-18x30.md`. Замечания к прошлому КП: `sales/kp-18x30-zamechaniya.md` (не повторять эти ошибки).

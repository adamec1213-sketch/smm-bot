# Конструктор П³ (p3-platform.ru) vs КП «Ангар 18×30×6», 18.11.2026

Модель построена в публичном конструкторе: складское, 30×18 м, шаг рам 6 м, один пролёт 18 м,
двускатная кровля ~6° (≈10 %), карниз 6,0 м; остальные параметры — по умолчанию
(снег 1,8 кПа, ветер 0,38 кПа, грунт «средний»). Цены не смотрели: «Рассчитать стоимость» требует контакты.

## Чего нет в П³ для таких КП (доработать)
1. Винтовые сваи с оголовками (кол-во по колоннам, диаметр, длина) — некапитальный вариант.
2. Пол из плит ПАГ по щебню (плиты, щебень, геотекстиль, кран, заливка швов).
3. Нижний прогон-швеллер по периметру вместо цоколя.
4. Вертикальная раскладка стеновых панелей с ригелями + фахверковые колонны торцов.
5. Фермы вместо сплошных балок (в КП каркас на фермах).
6. Минвата по умолчанию для КП (сейчас PIR) — проверить, что выбор попадает в смету.
7. Выбор «связи по кровле: нет» — сверить с расчётом.
8. Цены и наценка компании — свериться с калькулятором КП (не проверено).

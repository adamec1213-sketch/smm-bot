## Слайды (кратко)

1. **Цена ангара.** Обложка → проект → фундамент → каркас → стены и кровля → ворота и окна → монтаж → итог «от 20 000 ₽/м²» → контакты.
2. **Цена «от».** Обложка → что обычно в цене «от» (только каркас) → чего нет: фундамент, полы, ворота, утепление, доставка, монтаж → как сравнивать сметы → «всё включено» у нас → контакты.
3. **Холодный или тёплый.** Обложка → холодный: для чего → тёплый: для чего → толщина сэндвич-панелей → отопление → сравнение по цене → как выбрать → контакты.
4. **7 вопросов подрядчику.** Обложка → по слайду на вопрос (смета, сроки в договоре, гарантия, СРО, объекты, кто монтирует, что не входит) → контакты.
5. **Фундамент.** Обложка → плита → лента → сваи с ростверком → винтовые сваи (серая зона по капитальности) → как выбрать → контакты.
6. **Разрешение.** Обложка → ГПЗУ → проект → разрешение (ст. 51 ГрК РФ) → ввод в эксплуатацию → ЕГРН → что будет без разрешения (ст. 222 ГК РФ) → контакты.
7. **Зима.** Обложка → бетон зимой → монтаж каркаса → кровля и панели → сроки → плюсы зимней стройки → контакты.
8. **Кровля.** Обложка → по слайду на ошибку (плохая герметизация стыков, неправильный замок фальца, подрезка полки и др. — по видео владельца) → как принимать кровлю → контакты.
9. **Этапы.** Обложка → 9 этапов из карусели от 13.11 → контакты.
